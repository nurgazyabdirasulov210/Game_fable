# EMBERFIELD

Кооперативная 3D-игра на выживание (1–4 игрока) в браузере: исследование долины, сбор ресурсов, крафт, строительство базы, враги, смена дня и ночи, погода и сюжетная цель — восстановить радиостанцию и вызвать помощь.

Стек: **TypeScript · Three.js · Vite · Node.js · Socket.IO**. Все модели, иконки и звуки создаются процедурно — внешних ассетов нет.

## Установка и запуск

Требуется Node.js 20+.

```bash
npm install

# Разработка: сервер (порт 3001) + Vite (порт 5173) одновременно
npm run dev            # открыть http://localhost:5173

# Продакшен: собрать клиент и раздать его игровым сервером на одном порту
npm run build
npm start              # открыть http://localhost:3001   (порт меняется через PORT=...)
```

Одиночная игра работает и без сервера (например, `npm run dev:client`). Для игры с друзьями нужен запущенный сервер: хост нажимает «Играть с друзьями → Создать комнату» и отправляет код из 5 символов или ссылку-приглашение (`…/?room=КОД`, кнопка в меню паузы). Друзья должны иметь сетевой доступ к этому адресу (одна сеть или опубликованный порт).

### Тесты

```bash
npm run test:sim   # 16 тестов симуляции (мир, сбор, стройка, ИИ, ночь, погода, радио, сохранения)
npm run build && npm run test:e2e   # сквозной тест в headless Chromium (нужен Playwright): соло + кооператив
```

## Что реализовано

**Мир.** Долина 640×640 м с процедурным рельефом: кольцо гор, холмы, река, озеро, тропы, мост. ~1800 деревьев четырёх видов, валуны, кусты, трава с ветром (один draw call, шейдер), цветы и папоротники. Точки интереса: лагерь выживших, исследовательская станция, сторожевая башня (с лестницей), заброшенный посёлок, рыбацкая хижина с причалом. Опасные зоны: заражённая зона (радиация), гнездо мутантов, волчьи леса.

**Персонаж.** Вид от третьего лица, плавная камера с обходом препятствий, процедурные анимации (ходьба, бег, прыжок, удар, плавание, смерть), коллизии с рельефом, деревьями, камнями, зданиями и постройками, урон от падения, плавание.

**Выживание.** Здоровье, голод, жажда, выносливость; еда, вода, бинты, жарка мяса; тепло костра лечит; радиация, голод, жажда и утопление наносят урон; экран смерти и возрождение в лагере.

**Ресурсы.** Деревья → древесина, валуны и камни → камень, растения → волокна, кусты → ягоды, контейнеры → случайная добыча. Объекты реально меняют состояние (пень, щебень, пустой куст, открытый ящик) и восстанавливаются со временем.

**Инвентарь и крафт.** 24 ячейки, стаки, быстрые слоты, перемещение кликом и перетаскиванием. Рецепты: топор (5 древесины, 2 камня, 3 волокна), кирка, молоток, факел, копьё, бинт — ресурсы списываются.

**Строительство.** Фундамент, стена, дверь (открывается), костёр, ящик-хранилище на 12 ячеек. Предпросмотр, проверка места (вода, склон, пересечения), привязка стен и фундаментов друг к другу, списание и возврат ресурсов.

**Враги.** Волки и олени (животные), мутанты, ночной охотник (только ночью, боится костра, сгорает на рассвете). ИИ: блуждание, обнаружение, преследование, атака, бегство, получение урона, смерть, добыча.

**День/ночь и погода.** Солнце, луна, звёзды, облака, динамический свет и туман; ясно, дождь, туман, гроза с молниями и громом. Туман снижает обзор врагов, дождь замедляет жажду.

**Сюжет.** 7 заданий с наградами: дрова → камень → топор → костёр → найти станцию → собрать 3 детали и починить радио → включить передатчик и отбиться от волн мутантов → экран победы.

**Интерфейс.** Главное меню (новая игра, продолжить, играть с друзьями, настройки, выход), HUD (показатели, слоты, мини-карта, цель, часы, погода, список игроков), инвентарь, крафт, строительство, ящик, карта, пауза, смерть, победа, чат.

**Звук.** Процедурный WebAudio: шаги по траве/дереву/воде, рубка, камень, подбор, крафт, стройка, урон, рычание врагов, ветер, дождь, гром, костёр, птицы и сверчки, музыка меню.

**Сохранение.** Одиночная игра автоматически сохраняется в браузере (мир, постройки, инвентарь, задания) — кнопка «Продолжить».

### Что работает в мультиплеере

Сервер авторитетен: в каждой комнате работает та же симуляция, что и в одиночном режиме (`shared/room.ts`).

- создание комнаты, вход по коду и по ссылке, лимит 4 игрока, список игроков;
- синхронизация положения, анимаций и предмета в руке;
- общий мир: состояние деревьев, камней, кустов, контейнеров;
- общее строительство, двери, содержимое ящиков, разборка;
- общие враги (ИИ на сервере), время суток, погода;
- общая радиостанция (детали может установить любой игрок) и общая победа;
- чат, уведомления о входе и выходе игроков.

Инвентарь, показатели и задания у каждого игрока свои.

**Сохранение комнат.** Сервер записывает мир каждой комнаты в `data/rooms/КОД.json` (каждые 30 секунд, при выходе последнего игрока и при остановке сервера) и восстанавливает его при входе по тому же коду — в том числе после перезапуска. Личный прогресс (инвентарь, показатели, задания, позиция) хранится в браузере по коду комнаты; в лобби есть кнопка «Вернуться» в последнюю комнату. Комнаты, в которые не заходили 30 дней, удаляются. Каталог меняется переменной `DATA_DIR`.

## Что не реализовано и ограничения

- Сервер доверяет клиенту в части инвентаря и здоровья (кооператив, не соревновательная игра) — защиты от читов нет.
- Нет выделенного лобби с ожиданием: создатель комнаты сразу попадает в мир, друзья подключаются на ходу.
- Физика — собственный кинематический контроллер (карта высот + круги и повёрнутые боксы), без Rapier: этого достаточно для жанра, но нет физики предметов.
- Модели и анимации процедурные и намеренно простые (low poly из примитивов), скелетной анимации нет.
- Враги обходят препятствия простым уклонением, полноценного поиска пути нет.
- Карта одна (фиксированный сид), управление рассчитано на клавиатуру и мышь, геймпад и мобильные устройства не поддерживаются.
- Пол зданий и крыши — без многоэтажности у игрока: строить можно в один уровень.

## Структура проекта

```
shared/            общий код клиента и сервера
  rng.ts           детерминированный шум и ГПСЧ
  world.ts         рельеф, точки интереса, здания, ресурсы, коллизии
  items.ts         предметы, рецепты, постройки, добыча
  room.ts          авторитетная симуляция комнаты (ресурсы, враги, постройки, время, погода, радио)
server/index.ts    Socket.IO-сервер комнат + раздача собранного клиента
src/
  main.ts          главное меню и жизненный цикл игры
  game.ts          игровой цикл: управление, камера, выживание, действия, стройка, сеть
  net.ts           транспорт: локальная комната (соло) или Socket.IO (кооператив)
  inventory.ts, quests.ts, save.ts, settings.ts, audio.ts
  render/          terrain, sky, vegetation, structures, character, buildings (+ огонь, погода, частицы)
  ui/              hud.ts (HUD и окна), icons.ts, menubg.ts
  style.css
tests/
  sim.test.ts      тесты симуляции
  e2e.cjs          сквозной браузерный тест (соло + кооператив)
```

## Результаты тестирования

Проверено в headless Chromium (программный WebGL) и Node 22:

- `npm run test:sim` — 16/16;
- `npm run test:e2e` — 113 проверок: одиночная игра (меню, движение, коллизии, сбор, вода, крафт, кирка, все виды построек, дверь, ящик, разборка, выживание, волк, мутант, ночь и ночной охотник, факел, гроза, туман, карта, пауза, смерть, сохранение и «Продолжить», башня, детали, радио, волны, победа) и кооператив с двумя клиентами и настоящим сервером (комната, код, ссылка, синхронизация игроков, ресурсов, построек, ящика, двери, врагов, времени и погоды, чат, отключение, лимит 4 игрока, восстановление комнаты и инвентаря после перезапуска сервера); ошибок в консоли браузера нет.

Тест управляет игрой через настоящие события клавиатуры и мыши, а время симуляции продвигает вызовом `game.step()`, поэтому не зависит от частоты кадров. На реальном GPU производительность и ощущение управления автоматически не измерялись — в тестовой среде доступен только программный рендеринг.
